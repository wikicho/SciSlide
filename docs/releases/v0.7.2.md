# SciSlide 0.7.2 — PowerPoint import colors and equations

- PowerPoint import applies theme overrides, mapped default text colors, and supported color transforms such as luminance changes and transparency. This improves color fidelity when opening PPTX exported from Keynote.
- Supported Office Math formulas, including fractions, roots and scripts, import as editable inline LaTeX. If a formula cannot be converted, SciSlide keeps its embedded PNG, JPEG or SVG fallback when available. The import report identifies elements that were simplified or could not be imported.

Open a PPTX file through **Open presentation**, or drop it onto the canvas. Save the result as a `.scislide` file to keep editing it.

This development prerelease includes the [macOS dual-display fix from 0.7.1](v0.7.1.md). Regression tests cover generated PowerPoint fixtures with theme overrides and Office Math. Import fidelity can vary with the content stored by the original export.
