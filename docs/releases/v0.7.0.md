# SciSlide 0.7.0 — Dual-display presenting and PowerPoint import

- On extended desktop displays, **Present** keeps the current and next slide, speaker notes, timer and controls on the editor’s display. The other display shows the audience slideshow fullscreen. Navigation and click builds stay synchronized. With one display, **Present** opens the regular slideshow.
- Open or drop a **PowerPoint (.pptx)** file to bring its slide order, dimensions, notes, editable text and basic shapes, and supported embedded images into SciSlide. The import details identify omitted or simplified content by slide. Save the editable result as a **.scislide** file.
- MathJax and PDF export libraries load on demand. Embedded raster images avoid redundant base64 conversion, and smart guides reuse candidate calculations during each drag update.
- The desktop file picker can open several presentations in separate editor windows. Each window keeps its own save destination, Undo history and recovery state.

Complex PowerPoint content such as charts, tables, Office equations and animations can be omitted or simplified. Desktop display placement requires extended displays. Browser placement depends on browser support and permission for screen access and pop-ups. SciSlide source files retain format **0.5.0**. This is a development prerelease.

Linux testing used two virtual RandR outputs. In the packaged app, the audience window opened fullscreen on the second output, presenter notes stayed on the first, and navigation worked from either window. The same test imported a PowerPoint file with a table warning and saved editable text, a shape and speaker notes to a native file. Initial JavaScript fell from 12.32 MB in 0.6.10 to 0.84 MB in 0.7.0. Both installers bundle the offline equation resources.
