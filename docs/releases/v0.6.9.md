# SciSlide 0.6.9 — Authoring controls and large-document responsiveness

This development prerelease adds seven authoring controls and reduces repeated work when editing presentations with large embedded images. Native documents retain format **0.5.0**. Earlier v0.6.8 releases and validation records remain available separately.

## Authoring

- **Fit text boxes to content:** derive the text frame from its content without changing the font size. Manual resizing restores a fixed frame.
- **Partial colors:** color selected prose in the Inspector or canvas editor. Equation source tools wrap selected LaTeX terms in a scoped RGB color group. Source edits preserve selections and support Undo/Redo, including IME composition.
- **Editable bullets:** toggle bullets on selected lines; Enter continues a list and an empty bullet ends it. The underlying text stays editable.
- **First numbered slide:** choose where numbering begins and assign its starting value. Existing numbering behavior remains available for older documents.
- **PDF animation pages:** optionally export each reveal step as a PDF page while retaining its original slide number. The headless PDF CLI accepts `--build-steps`.
- **User layouts:** save a slide as a named local layout, insert independent editable copies, update a layout from an edited copy, and remove saved entries. Stored content retains its figures, equations and formatting; page dimensions must match.
- **Command favorites:** save reusable `\newcommand` definitions locally. Using a favorite copies definitions into MathJax source or the Local LaTeX preamble, so files remain self-contained. Inline macros with multiple source lines use parenthesized math delimiters. Local LaTeX compilation remains explicit.

## Responsiveness and validation

Offscreen slide/layout previews defer SVG work; unchanged text measurements and inline layouts are reused. Identical active MathJax requests share a conversion while errors remain retryable. Document comparison, cloning and recovery avoid repeatedly serializing or decoding unchanged media. Caches are bounded, and changed media/MIME values still pass validation and SVG sanitization.

The isolated source passed **1,291 editor/CLI tests across 98 files**, TypeScript and production web/CLI builds. Linux Electron preview checks used isolated profiles and document copies. In one fresh-profile comparison with warmed filesystem caches, the same **49,868,097-byte** image-heavy native archive opened in **9,532 ms** on official 0.6.7 and **4,525 ms** on the isolated improved preview; a measured return to slide 1 changed from **6,435 ms** to **62 ms**. These observations are not guarantees for every machine or document. The improved idle sample still included a **223 ms** long task. The fixture exercises stored raster media, including the asset path used by imported PDF pages; it does not benchmark PDF import itself.

See the [authoring/performance review](https://github.com/wikicho/SciSlide/blob/v0.6.9/docs/specifications/authoring-performance-2026-11-17.md) for scope, native checks and evidence. Windows/macOS manual interaction and broader OS integration remain separate checks. Existing unsigned-installer, Local LaTeX, font-format and PPTX limitations still apply.
