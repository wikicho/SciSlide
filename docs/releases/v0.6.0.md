# SciSlide 0.6.0 — Scientific authoring update

This development prerelease adds direct slide editing, inline mathematics, a coordinated Keynote White theme and richer scientific figure workflows. The same editor runs in the browser and Electron.

## What's new

- **Inline LaTeX in text:** write `$...$` or `\(...\)` alongside English or Korean prose. MathJax formulas inherit the deck's math font, match the surrounding font's measured lowercase height and preserve their mathematical baseline. Whole formulas wrap with the text; tall fractions expand their own line's spacing. SVG/PDF retain vector mathematics and selectable ordinary text. Editing and native saves preserve the original source.
- **Theme-first startup and direct text editing:** choose Scientific, Minimal White, Minimal Black, Navy or Keynote White before creating a presentation. Double-click a text box or press Enter to edit on the slide. Command/Ctrl+Enter applies one undoable edit; Escape cancels. Korean IME input, plain-text paste, rotation and zoom are supported.
- **Keynote White:** fifteen coordinated white/black layouts for titles, bullets, photos, sections, agendas, statements, facts, quotes and video placeholders, plus Blank. The existing four themes retain their fourteen-layout picker. Selecting a photo/video placeholder before importing fills its frame; photo crops remain adjustable. No Apple photographs or live-camera feed are bundled.
- **Scientific figures:** import sanitized SVG/PNG/JPEG or preview a PDF and select one page. PDF pages are embedded as high-resolution PNGs. Apply or reset a reversible crop, create an independent enlarged inset, or replace a source while preserving its frame and crop. Supported SVG content remains vector graphics in PDF/SVG output.
- **Editing conveniences:** copy/cut/paste objects and groups across slides or decks in one session; select hidden or covered objects through the object/layer list; align selections in six directions and distribute equal horizontal or vertical gaps.
- **Platform shortcuts:** Command/Option on macOS and Ctrl/Alt on Linux/Windows, with Windows Ctrl+Y Redo, native-menu integration and a platform-specific help dialog. Text-field and IME editing retain their normal behavior.
- **My equations:** a searchable local library with names, tags, editable source/style and JSON import/export. Inserted equations are independent; Local LaTeX entries require explicit Compile → Apply.
- **Recovery and presentation:** bounded IndexedDB workspace recovery now retains committed decks and up to 200 unfinished equation drafts, with a localStorage fallback. A separate presenter window shows current/next previews, speaker notes, navigation and a configurable timer.
- **Linux distribution:** an x64 `.deb` installs the complete Electron runtime, launcher and desktop icon. Install with `sudo apt install ./SciSlide-0.6.0-linux-x64.deb`, then launch `scislide`. Debian architecture is `amd64`; Ubuntu 24.04 x64 is the packaging target.

## Downloads and compatibility

Choose the asset matching your system and verify its accompanying `.sha256` file:

- macOS: arm64 `.pkg` for Apple Silicon or x64 `.pkg` for Intel. See the [macOS guide](https://github.com/wikicho/SciSlide/blob/v0.6.0/desktop/MACOS.md).
- Windows: x64 setup `.exe` or portable `.zip`. See the [Windows guide](https://github.com/wikicho/SciSlide/blob/v0.6.0/desktop/WINDOWS.md).
- Linux: x64 `.deb`. See the [Linux guide](https://github.com/wikicho/SciSlide/blob/v0.6.0/desktop/LINUX.md).

macOS installers remain unsigned and unnotarized; Windows distributions remain unsigned. System security policies may block installation or launch. Packaging checks and browser review do not establish complete physical-device validation on every operating system.

New `.scislide` saves use native format **0.5.0**, including reversible figure crops. Formats **0.1.0–0.4.0** are migrated when opened; the original file changes only when saved. Older SciSlide versions that read only 0.4.0 or earlier cannot open new 0.5.0 files. Use **Save As** to retain an older original. Personal libraries and unapplied equation drafts are local workspace data, separate from portable deck files.

MathJax needs no TeX installation. Installed-package compilation remains available only through the supported Linux Local LaTeX workflow, requiring working isolation and bubblewrap 0.9.0 or later. macOS/Windows Local LaTeX compilation remains unavailable. Inline text formulas use MathJax rather than installed TeX packages.

## Examples and remaining limits

Try the editable [inline mathematics example](https://github.com/wikicho/SciSlide/blob/v0.6.0/examples/inline-math.scislide) and [fifteen-layout Keynote White example](https://github.com/wikicho/SciSlide/blob/v0.6.0/examples/keynote-white-theme.scislide).

Original PDF vector import, automatic multi-monitor placement, PPTX/HTML export, advanced animation and linked masters remain future work. Modern Korean prose uses bundled Nanum Gothic; unsupported body-text glyphs still produce a PDF export error. No hosted SciSlide APT repository, automatic APT updates or Snap Store package is provided.
