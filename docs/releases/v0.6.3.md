# SciSlide 0.6.3 — Inline equation editing and focused keyboard commands

This development prerelease adds inline equation popups, improved text frame controls, context-aware keyboard navigation and native menu availability. Linux gains a shortcut for explicit Local LaTeX compilation, and desktop packages include a CLI that checks for updates and downloads verified installers. Platform shortcuts continue to follow Keynote on macOS, PowerPoint on Windows and LibreOffice Impress on Ubuntu/Linux.

## What's new

- **Inline equation editing:** press **⌘+Shift+M** on macOS or **Ctrl+Shift+M** on Windows/Linux in canvas or Inspector text to open a LaTeX popup with a live MathJax preview. Insert a formula at the caret, edit the formula containing the caret, or double-click a rendered inline formula. Applying preserves surrounding prose; cancel restores the previous text and selection. A selected text object also supports the shortcut. Typing dollar delimiters directly stays in the text field; use `\$` for a literal dollar sign.
- **Text frame controls:** text grows vertically to fit its content using loaded-font metrics. Moving and resizing preserves rotated text placement. Inspector text size and frame width/height inputs commit on Enter or blur and cancel pending values with Escape. Left/center/right text alignment remains in the Inspector; equal-gap distribution remains available in the toolbar.
- **Canvas and panes:** **Tab / Shift+Tab** selects eligible objects in back-to-front stacking order, treating a flat group as one unit and skipping hidden/locked content. At the boundaries, Tab returns to ordinary UI focus order. Inspector and Objects & Layers can be shown independently; their shortcuts focus a shown pane or return to the canvas when hidden. Use **⌘+Option+I / ⌘+Shift+L** on macOS or **Ctrl+Alt+I / Ctrl+Shift+L** on Windows/Linux.
- **Focused slide commands:** duplication targets the focused thumbnail even when the canvas retains an object selection, selects and focuses its copy, and creates one undoable edit. macOS thumbnail reordering uses **⌘+Option+Up / Down** for one position and **⌘+Option+Shift+Up / Down** for first/last. Windows/Linux bindings and aliases remain available.
- **Linux equation workflow:** **Alt+Shift+E**, or legacy **Ctrl+Alt+=**, inserts an equation, reveals Inspector and focuses **LATEX SOURCE**. **Ctrl+Shift+Enter** compiles one selected visible, unlocked Local LaTeX equation when installed TeX is ready and the editor is idle. It works from the canvas or equation Inspector, including source and preamble. Compilation updates only the draft preview; **Apply equation** remains a separate action.
- **Command-line update downloads:** **`scislide --check-update`** checks GitHub Releases; **`scislide --update`** downloads a newer matching installer and verifies SHA-256. Downloads default to `~/Downloads/SciSlide-updates`; use `--output DIR` to change it or `--stable` to exclude development prereleases. The CLI prints the installer path and installation command. **Installation remains a separate step**, after closing the editor. Packaged launchers use the bundled runtime without an editor window or a separate Node installation.
- **Documentation:** the managed GitHub wiki includes installation, editing, equations, exports, troubleshooting, development and the shortcut specification. Source documentation changes publish through the wiki workflow.

The [README keyboard reference](https://github.com/wikicho/SciSlide/blob/v0.6.3/README.md#keyboard-shortcuts) lists commands and compatibility aliases. The native `.scislide` document format remains **0.5.0**.

## Shortcut routing and editing fixes

A shared command registry supplies platform keys, aliases, focus scope, availability and repeat policy to renderer shortcuts and native menus. Native menu enabled states follow current focus, selection, clipboard/history availability, dialogs and busy operations. Focused text retains native clipboard, selection and history behavior, including inside modal text controls; disabled application commands do not dispatch.

Audience and presenter use the same playback resolver. Editable/media controls retain all keys, including Escape; focused buttons retain Space/Enter. Plain Escape exits from presentation focus. Navigation, endpoints and exit ignore auto-repeat. Shift+arrow preserves ordinary build navigation; other shifted playback keys are ignored. IME composition, AltGraph and unrelated modifiers remain protected. The Linux compile shortcut stays disabled in browser/MathJax mode and does not interrupt notes, inline text, media, thumbnails, dialogs or playback.

The release workflow builds all five distributions from the same source commit and verifies checksums and architecture. Updater regression checks cover platform selection, checksum failures, download paths and preservation of existing files. Automated tests and packaging checks do not establish complete editing, saving, media and export validation on every physical desktop. Native macOS application/window roles still require physical-platform validation. Browser-reserved or desktop-environment shortcuts can take precedence; toolbar commands remain available.

## Document compatibility and remaining limits

The native `.scislide` format remains **0.5.0**; this release does not introduce a format migration. Formats **0.1.0–0.4.0** are migrated on opening, and the original file changes only when saved. Apps that read only 0.4.0 or earlier cannot open new 0.5.0 saves. Use **Save As** to preserve an older original. Personal equation libraries and unapplied drafts remain local workspace data, separate from portable presentation files.

Installed-package LaTeX compilation remains Linux-only and requires working isolation with bubblewrap 0.9.0 or later. macOS/Windows Local LaTeX compilation remains unavailable. Inline text formulas use MathJax. Video playback is available in presentation mode; PDF/SVG exports contain static video placeholders. Original PDF vector import, PPTX/HTML export, advanced animation, linked masters, automatic background updates/installation, a hosted APT repository and Snap distribution remain future work. The update CLI downloads installers; it does not install them automatically.
