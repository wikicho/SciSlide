# SciSlide 0.6.4 — PowerPoint export and starter themes

This development prerelease adds PowerPoint export and three editable starter themes.

## What's new

- **PowerPoint export:** export the presentation as a `.pptx` from the editor or desktop File menu. Text and shapes remain editable; equations and figures are embedded graphics. Slides retain their dimensions, order, page numbers and speaker notes.
- **Geometric, Dune and Ocean themes:** start with a coordinated color palette and an editable cover made from ordinary slide objects.

PowerPoint equations are graphics rather than editable Office equations. Click builds export in their final state and videos become static placeholders. Install the presentation's fonts on the destination computer to avoid substitution. Keep the original `.scislide` file for editing LaTeX and SciSlide-specific settings. See [Export and presenting](https://github.com/wikicho/SciSlide/wiki/Export-and-Presenting) for details.
