# SciSlide 0.7.1 — macOS dual-display presentation

On macOS, the audience window now moves to the second display and becomes visible before SciSlide enters simple fullscreen. This gives AppKit the correct display when it calculates the fullscreen frame. The presenter window keeps focus. Closing the audience window ends simple fullscreen and restores the macOS menu bar and Dock settings.

Set the displays to **Extend**, open SciSlide on the display where you want your notes, and select **Present**. The other display shows the slides. Consult [Apple’s instructions for extending the desktop](https://support.apple.com/guide/mac-help/mchlb5f905a1/mac) if both displays show the same desktop.

The release retains PowerPoint import and the startup optimizations from 0.7.0. Automated tests check the macOS window placement sequence, including a display to the left of the presenter and disconnection during playback. This is a development prerelease.
