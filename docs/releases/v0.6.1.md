# SciSlide 0.6.1 — Slide reordering and desktop packages

This development prerelease adds drag-and-drop slide ordering and consistent Linux Debian output paths. The shared browser/Electron editor retains the scientific authoring features introduced in 0.6.0.

## What's new

- **Drag slides to reorder:** drag a thumbnail above or below another thumbnail. A teal insertion line shows the destination, and the list scrolls when dragging near its top or bottom edge.
- **Preserve editing context:** reordering keeps the current slide and selected objects active. Page numbering, presentation navigation, saved decks and PDF export follow the new order. Each completed move is one Undo/Redo step; hovering and moves that leave the order unchanged do not add history entries.
- **Cancel without changing the deck:** press Escape or release outside the slide list. The existing move-up/move-down buttons remain available.
- **Consistent Linux output:** Debian packaging now defaults to `release/linux-deb/`, including the `.deb`, checksum, guide and complete app folder. `--out` still selects another directory. macOS packages are kept in `release/macos-pkg/` and Windows distributions in `release/windows-x64/` when using those explicit output options.

MathJax editing needs neither Node.js nor a TeX installation.

macOS installers are **unsigned and unnotarized**; Windows distributions are **unsigned**. System security policies may block installation or launch. Checksums detect file changes and do not authenticate the publisher. Windows distributions target x64, with Windows 10 or later required and Windows 11 the intended desktop target. Linux packaging targets Ubuntu 24.04 x64; other Debian/Ubuntu releases require separate validation. No native Windows/Linux ARM64 package is provided.

The release workflow builds all five distributions from the same requested source commit and verifies checksums and architecture. Automated packaging checks do not establish complete editing, saving, media and export validation on every physical desktop.

## Document compatibility and remaining limits

The native `.scislide` format remains **0.5.0**; this release does not introduce another format migration. Formats **0.1.0–0.4.0** are migrated on opening, and the original file changes only when saved. Apps that read only 0.4.0 or earlier cannot open new 0.5.0 saves. Use **Save As** to preserve an older original. Personal equation libraries and unapplied drafts remain local workspace data, separate from portable presentation files.

Installed-package LaTeX compilation remains Linux-only and requires working isolation with bubblewrap 0.9.0 or later. macOS/Windows Local LaTeX compilation remains unavailable. Inline text formulas use MathJax. Video playback is available in presentation mode; PDF/SVG exports contain static video placeholders. Original PDF vector import, PPTX/HTML export, advanced animation, linked masters, automatic updates, a hosted APT repository and Snap distribution remain future work.
