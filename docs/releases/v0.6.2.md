# SciSlide 0.6.2 — Keyboard shortcuts for each platform

This development prerelease adds Keynote-style shortcuts on macOS, PowerPoint-style shortcuts on Windows, and LibreOffice Impress-style shortcuts on Ubuntu/Linux. Native menus, toolbar hints and the keyboard reference use the same platform profile. Existing scientific authoring features and drag-and-drop slide ordering remain available.

## What's new

- **macOS:** use **⌘+Shift+N** for the slide-layout chooser, **⌘+Option+E** for equations, **⌘+Option+P** to present, and **⌘+Option+G / ⌘+Option+Shift+G** to group/ungroup. Object locking, layer order, zoom, bold, text size and text alignment have shortcuts matching supported Keynote actions. PDF export moves to **⌘+Option+Shift+P** to keep presentation and export separate.
- **Windows:** **Ctrl+M** opens the slide-layout chooser, **Ctrl+Shift+D** duplicates the current slide, **Alt+=** inserts an equation, and **Alt+F5** opens the presenter display. **Ctrl+G / Ctrl+Shift+G** group/ungroup, **Ctrl+Shift+] / [** change one object layer, **Ctrl++ / -** zoom, and **Ctrl+Alt+O** fits the slide to the window.
- **Ubuntu/Linux:** **Ctrl+M** opens the slide-layout chooser, **Shift+F3** immediately duplicates the selection or current slide, and **Alt+Shift+E** inserts an equation. **Ctrl+Shift+G / Ctrl+Alt+Shift+G** group/ungroup. **Ctrl++ / -** change one layer and **Ctrl+Shift++ / -** send an object to the front/back; use numeric-keypad **+**, or main-keyboard **Ctrl+= / Ctrl+Shift+=** for forward/front. Bare **+ / -** zoom; numeric-keypad **\*** fits the slide.
- **Windows and Linux presentation controls:** **F5** starts at the first slide; **Shift+F5** starts at the current slide. **Enter / Backspace** advance/reverse a build or slide. Windows also accepts **N / P**; Linux also accepts **-** to exit. **F1** opens shortcut help.
- **Slide navigation and ordering:** **Page Up / Page Down** and **Home / End** navigate the deck. When a thumbnail has focus, Windows **Ctrl+Up / Down** moves it one position and **Ctrl+Shift+Up / Down** moves it first/last. Linux uses **Alt+Shift+Page Up / Down** and **Alt+Shift+Home / End**, with **Ctrl+Shift+Up / Down / Home / End** aliases. Thumbnail arrow and delete keys work on all platforms.
- **Text formatting:** supported shortcuts change bold, size and alignment on whole selected text objects. Windows uses **Ctrl+Shift+> / <** for size; Linux uses **Ctrl+] / [**. Both use **Ctrl+B** and **Ctrl+L / E / R** for bold and left/center/right alignment.

The [README keyboard reference](https://github.com/wikicho/SciSlide/blob/v0.6.2/README.md#keyboard-shortcuts) lists all commands and compatibility aliases. Linux **Ctrl+Shift+G** now groups, matching Impress; **Ctrl+G** remains a grouping alias. Linux duplication performs an immediate copy, without Impress's duplication-options dialog.

## Shortcut routing and editing fixes

Shortcut handling preserves text-field clipboard, navigation, Undo/Redo and IME input. **Command/Ctrl+Enter** applies an inline text edit before any presentation action. Unrelated canvas commands remain suppressed while editing text or using a dialog, and slide-order commands require thumbnail focus. A focused slide thumbnail duplicates the slide even if the canvas retained an object selection.

Keyboard matching checks modifiers, composition and AltGraph input, and supports physical keys for non-Latin input layouts. Numeric-keypad and main-keyboard plus commands stay distinguishable on Linux. Native presentation menu actions enter fullscreen only when the editor can start a slideshow; typing, dialogs, text controls and presentation media controls keep their own keyboard behavior.

Automated tests and packaging checks do not establish complete editing, saving, media and export validation on every physical desktop. Browser-reserved or desktop-environment shortcuts can take precedence; toolbar commands remain available.

## Document compatibility and remaining limits

The native `.scislide` format remains **0.5.0**; this release does not introduce a format migration. Formats **0.1.0–0.4.0** are migrated on opening, and the original file changes only when saved. Apps that read only 0.4.0 or earlier cannot open new 0.5.0 saves. Use **Save As** to preserve an older original. Personal equation libraries and unapplied drafts remain local workspace data, separate from portable presentation files.

Installed-package LaTeX compilation remains Linux-only and requires working isolation with bubblewrap 0.9.0 or later. macOS/Windows Local LaTeX compilation remains unavailable. Inline text formulas use MathJax. Video playback is available in presentation mode; PDF/SVG exports contain static video placeholders. Original PDF vector import, PPTX/HTML export, advanced animation, linked masters, automatic updates, a hosted APT repository and Snap distribution remain future work.
