# SciSlide 0.6.4.1 — Safer documents, external input and independent typography

This development update improves document switching, recovery, clipboard handling, file drops and typography. It also includes the independent Latin Modern inline-math preference prepared after v0.6.4. Native documents retain format **0.5.0**.

## Editing and document safety

- **Save, discard or cancel:** opening another document, creating a presentation and closing the desktop editor check for unsaved work. A validated document becomes the active Save destination only after confirmation. Replacing a document resets Undo/Redo, and failed reads or cancelled/failed saves preserve the current document and destination.
- **Recovery freshness:** startup compares valid IndexedDB and localStorage snapshots and restores the newest dated record. Legacy records without dates retain unknown age. Serialized recovery writes preserve their order and include unapplied equation drafts.
- **Document recovery history:** open local session copies from File → Recovered documents or the startup screen. Copies include unfinished equation drafts and restore into independent editing sessions without an original file destination. Keep recovery and continue saves the current copy before a document transition; a failed recovery write cancels the transition. The bounded history never automatically evicts older work, and removal requires a separate confirmation.
- **System clipboard:** object and slide copies include editable structure, groups, notes and referenced assets. Canvas paste accepts current system text and image content, including screenshots. External clipboard changes replace previously copied internal content. Focused text controls retain native clipboard and history commands, including in dialogs; failed clipboard writes retain cut originals.
- **External file drops:** drop local PNG, JPEG or SVG files onto the canvas at the insertion position. Multiple images retain file order and form one Undo step. A single PDF opens the existing page picker; a single `.scislide` file uses the document confirmation flow. Invalid batches leave the document unchanged. Web-image URL drops display a supported-input message.

Async image imports, clipboard reads and equation work check their destination session so an earlier document operation cannot insert into a reopened document with the same ID.

## Typography and output

- **Independent text and math settings:** choose Inter or Nanum Gothic as the deck text default. New text follows that default; existing text can keep an explicit family or return to the deck default. Standalone MathJax equations can remove their typography overrides and follow future deck changes.
- **Latin Modern inline mathematics:** inline equations default to Latin Modern independently of standalone equations. Choose Latin Modern, STIX Two or Fira Math in the inline-math setting. The preference is saved with the document and used by editing previews and SVG/PDF/PPTX layout. Changing text or standalone-equation fonts retains the inline choice. Text objects can override or inherit that choice, and cross-document copies preserve the source inline glyphs.
- **Visible inline source:** source controls use bounded placement and scrolling for large text frames, including zoomed or rotated content.
- **Imported SVG styles:** importing and exporting use the same restricted stylesheet policy. Supported embedded font declarations survive SVG and PowerPoint output; each figure's font families are isolated to avoid collisions. PDF can embed supported normal TrueType figure fonts and reports unsupported formats, styles or missing glyphs instead of silently substituting them.
- **Earlier output feedback:** known PDF restrictions in visible imported SVG text, embedded fonts and effects are reported during import and in the figure Inspector. Unused font declarations remain quiet; final export still validates actual glyphs.
- **Packaged CLI PDF:** supported embedded-font SVG figures now share font registrations between PDF output and text measurement. This fixes missing CSS constructor and unavailable figure-font errors in the headless exporter, with real-font native round-trip and PDF regression coverage.
- **Archive metadata:** the producer version comes from the application package version rather than a fixed historical string. Application and document-format versions remain separate.

Local LaTeX still uses the selected engine and preamble and requires explicit compilation. Latin Modern math support does not add a Latin Modern body-text font. Unapplied equation drafts belong to local recovery; apply them before choosing **Save changes** during a document transition, choose **Keep recovery and continue** to preserve them locally, or choose to discard the active changes. Previously autosaved history copies remain until explicitly removed.

## Editing experience

Multiple selections now show their scope and group/lock/visibility state, with a direct route to Arrange tools or one member's style. Individual style and geometry fields appear for one selected object, avoiding accidental edits to only the first item in a multiple selection. Empty slides offer text, equation and figure starting actions, and canvas hints follow the current editing state.

Toolbar menus close when focus leaves, support keyboard navigation and return focus without taking it from an editor or dialog opened by the action. File-save status, pending local recovery and unapplied equation drafts have separate labels. Document transitions explain drafts before disabling file saving and emphasize keeping recovery.

## Release preparation and validation

The combined release workflow continues to build macOS arm64/x64 installers, Windows x64 setup/portable distributions and the Linux x64 Debian package from one source commit, with matching checksums and platform guides. The Windows TeX discovery fixture now uses the host's PATH delimiter and executable suffix. Cached Electron archives are validated against the installed dependency's checksum manifest. The agent CLI also supports setting or clearing the deck inline-math font independently of body and standalone-equation fonts.

Manual release dispatch adds an explicit `stable` channel; the default remains `prerelease`. Stable publication requires a version without a prerelease suffix, preserves the complete verified artifact requirement and marks the release as latest only after upload verification. Source pushes continue to use prereleases, and an existing tag's channel cannot be changed implicitly. The updater includes prereleases by default; `--stable` selects stable releases only.

Regression coverage exercises document transitions and failed/cancelled saves, recovery selection, clipboard encoding and native boundaries, drop coordinates and batch Undo, independent typography, inline-source placement, and imported-font output. Automated checks do not establish complete installed-app validation on Windows, macOS or Linux. Installation, file associations, real OS clipboard behavior, editing/save/reopen/export and update journeys still require checks on each supported platform.

PPTX text fonts are not embedded. Equations remain separate graphics, so editing text in PowerPoint does not automatically reflow adjacent equations. macOS installers remain unsigned and unnotarized, and Windows distributions remain unsigned. HEPSlide renaming, extension/Feynman-diagram modules and the project-source license decision remain separate work. This update does not declare the 1.0 release criteria complete.
